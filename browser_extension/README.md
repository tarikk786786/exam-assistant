# AI Exam Assistant Pro — Chrome Extension (Full Feature Edition)

A full-featured Chrome Extension built to inspect exam questions, provide instant academic verification, evaluate options with free AI, and track study progress securely without automating test submissions.

## 🌟 Key Features

1. **Question Inspection & Reading:**
   - Detects question stems and multiple-choice options automatically.
   - Supports highlighted text selection on any website or practice portal.
   - Detects session expiration and portal error notices.

2. **Dual-Tier Answer Verification:**
   - **Free Offline Mode (Default):** Built-in forensic science & pathology reference rules (no API key, login, or internet required).
   - **Free AI Tier (Google Gemini):** Integrates directly with the Google Gemini API (Free tier from `aistudio.google.com`).

3. **Human-Controlled Answer Review & Audit:**
   - Select and compare options interactively.
   - Flag tricky questions for later review.
   - Local session tracking in `chrome.storage.local` with question count, answer count, and flagged counter.

4. **Security & Academic Integrity:**
   - Never submits live exams or alters portal submission buttons.
   - API keys and logs stay strictly inside your local browser.

## 🚀 How to Install in Chrome

1. Open **Google Chrome**.
2. Visit `chrome://extensions/` in your address bar.
3. Turn on the **Developer mode** toggle in the top-right corner.
4. Click the **Load unpacked** button in the top-left corner.
5. Select the folder:
   ```text
   C:\Users\tarik\Desktop\MY TOOLS\apps\study_assistant_extension
   ```
6. Pin **AI Exam Assistant Pro** from the extensions toolbar.
